# Walmart Customer Purchase Analysis

## Project Objective
Analyze customer purchase behavior using statistical analysis and visualization.

## Techniques Used
- Data Cleaning
- Outlier Detection
- EDA
- Central Limit Theorem
- Confidence Intervals
- Data Visualization

## Tools & Libraries
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib

## Key Insights
- Male customers spend more on average than female customers
- Purchase distribution is right-skewed
- Larger sample sizes reduce confidence interval width
