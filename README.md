# Walmart Customer Purchase Behavior Analysis

## Project Objective

The objective of this project is to analyze customer purchase behavior at Walmart using statistical analysis and data visualization techniques. For the understanding of:
- Customer spending patterns
- Differences in purchasing behavior between male and female customers
- Distribution of purchase amounts
- Outliers and high-value transactions
- Population spending estimation using Central Limit Theorem (CLT) and Confidence Intervals

## Skills and Tools Used
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Outlier and null value detection
- Statistical analysis
- Visualization of customer behavior
- Confidence Interval estimation using CLT

## Tools & Libraries
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib

## Key Insights
- Male customers spend more on average than female customers
- Purchase distribution is right-skewed
- Larger sample sizes reduce confidence interval width

## The analysis helps generate business insights that can support:
- Customer segmentation
- Personalized marketing
- Revenue optimization
- Inventory planning
- Sales forecasting

The final goal of this project is to help Walmart make data-driven business decisions by identifying customer spending trends and purchasing behavior patterns.
